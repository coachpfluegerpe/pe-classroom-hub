I created these files for a smart board being used in a gym at a special needs school. The purpose is to increase student participation and interaction by giving the students an outlet where they can go to the board for their needs and then participate in the activity.
The students that use this file are all ages and grades from kindergarten to high school and varying levels of anxiety, autism, and other behaviors. 
This is part of a grant project to see how using an interactive board in the gym can improve student engagement.
